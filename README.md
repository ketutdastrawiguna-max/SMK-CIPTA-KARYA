# SmartEdu Bali — Portal Layanan & Edukasi Vokasi Berbasis AI

Aplikasi web portal interaktif yang dirancang untuk memperkenalkan program keahlian vokasi dan memberikan konsultasi minat studi menggunakan asisten berbasis AI. Proyek ini dikembangkan untuk mengikutserti kompetisi **Bali DigiFest 2026 (AI Web Innovation Challenge)**.

## 📌 1. Problem & Background

Kebutuhan akan informasi pendidikan vokasi dan penyelarasan keahlian siswa dengan industri di Bali semakin meningkat, khususnya pada sektor teknologi informasi, ekonomi kreatif, dan bisnis digital. Namun, calon siswa maupun masyarakat sering menghadapi beberapa kendala utama:

* **Problem:** Calon siswa kerap bingung menentukan jurusan vokasi yang sesuai dengan potensi dan minat diri.

* Informasi layanan sekolah dan portofolio karya siswa yang tersebar serta kurang terstruktur secara interaktif (web sekolah konvensional cenderung statis dan kaku).

* Kurangnya akses langsung untuk mendapatkan konsultasi awal terkait pilihan jurusan vokasi secara instan dan personal.

Pengembangan solusi berbasis web yang responsif dengan dukungan Kecerdasan Buatan (*Artificial Intelligence*) menjadi sangat krusial untuk menjembatani calon peserta didik, sekolah, dan kebutuhan dunia kerja di Bali.

## 🎯 2. Target User

* **Calon Siswa / SMP:** Membutuhkan panduan dan konsultasi interaktif untuk menentukan pilihan jurusan vokasi (PPLG, TJKT, DKV, Akuntansi) yang pas dengan minat mereka.

* **Orang Tua / Masyarakat:** Membutuhkan akses cepat mengenai profil, karya unggulan, dan kualifikasi kelulusan sekolah.

* **Mitra Industri / Komunitas:** Membutuhkan informasi mengenai potensi kolaborasi, karya siswa, serta kontak resmi sekolah secara efisien.

## 💡 3. Proposed Solution

**SmartEdu Bali** hadir sebagai aplikasi berbasis web yang menggabungkan portal informasi interaktif dengan asisten rekomendasi cerdas berbasis AI.

**User Journey Utama:**

1. Pengguna membuka portal web SmartEdu Bali dan menjelajahi informasi program keahlian serta portofolio karya.

2. Pengguna memanfaatkan fitur asisten AI untuk berkonsultasi mengenai minat belajar, bakat, atau kebutuhan kolaborasi.

3. Asisten AI menganalisis input pengguna dan memberikan rekomendasi jurusan vokasi atau informasi layanan sekolah yang paling relevan secara real-time.

## 🤖 4. AI Implementation & Tech Stack

* **Bagian yang Menggunakan AI:** Asisten Konsultasi & Rekomendasi Jurusan (Smart Interactive Assistant).

* **Model / API:** Gemini Pro API / Large Language Model (LLM) Integration.

* **Input:** Teks pertanyaan/deskripsi minat pengguna (misal: *"Saya suka mendesain gambar dan membuat video, jurusan apa yang cocok?"*).

* **Output:** Rekomendasi program keahlian yang sesuai beserta penjelasan alur belajar dan potensi karir vokasi di Bali.

* **Alasan AI Diperlukan:** Menggantikan proses konsultasi manual yang memakan waktu dengan layanan personal interaktif 24/7 yang mampu memahami preferensi bahasa alami pengguna secara fleksibel.

* **Tech Stack & Libraries:**

  * **Frontend:** HTML5, CSS3, JavaScript (ES6+)

  * **Fonts & Assets:** Google Fonts (DM Sans, Manrope), Unsplash Open License

## ✨ 5. MVP & Key Features

### Core Features (Sudah Berfungsi pada Submission):

1. 🏫 **Interactive Vocation Showcase:** Tampilan profil sekolah, pilihan program keahlian (PPLG, TJKT, DKV, Akuntansi), dan karya siswa yang responsif dengan dukungan *light/dark mode*.

2. 🤖 **AI Vocation Assistant Widget:** Antarmuka percakapan interaktif yang terhubung langsung dengan AI untuk menjawab pertanyaan seputar jurusan dan rekomendasi studi.

3. 🌓 **Adaptive Theme:** Dukungan mode terang (*light*) dan mode gelap (*dark*).

4. 📱 **Fully Responsive:** Tampilan teroptimasi untuk desktop maupun smartphone.

5. 📄 **Downloadable School Profile & Direct Contact:** Fitur pengunduhan profil resmi dan tautan komunikasi langsung.

## 🌟 7. Innovation & Differentiation

* **Interaktif & Personal:** Tidak hanya menampilkan teks statis seperti web sekolah konvensional, tetapi memberikan saran terpersonalisasi melalui AI.

* **Aksesibilitas Modern:** Desain antarmuka ringan, responsif di perangkat mobile, serta mendukung opsi kemudahan navigasi (*skip links*, *responsive drawer*).

## 🚀 8. Impact & Development Potential

* **Dampak:** Membantu calon siswa di Bali menemukan arah minat vokasi secara tepat dan meningkatkan transparansi kualitas pendidikan vokasi kepada publik.
