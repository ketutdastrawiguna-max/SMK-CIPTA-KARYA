## 💎 1. Project Overview & Description
**SmartEdu Bali** hadir sebagai solusi revolusioner dalam bentuk platform web portal pendidikan vokasi terpadu. Sistem ini dirancang khusus untuk menjembatani kolaborasi digital yang mulus antara siswa, tenaga pengajar, dan dunia industri di Bali ke dalam satu ekosistem yang efisien, transparan, dan modern.

---

## 🎯 2. Problem Statement & Target User
* **The Challenge (Masalah):** Kompleksitas pengelolaan informasi akademik harian, minimnya transparansi dalam pencatatan kas/keuangan kelas, serta sulitnya akses modul kejuruan yang terpusat bagi para pelajar SMK.
* **The Solution (Target User):** Dirancang secara intuitif khusus untuk **Siswa SMK**, **Dewan Guru/Pengajar**, serta **Administrator Sekolah Vokasi** agar operasional harian sekolah menjadi jauh lebih terstruktur.

---

## ⚡ 3. Core Features & Capabilities
* **📊 Interactive Academic Dashboard:** Pusat informasi terpadu yang menyajikan rekapitulasi kegiatan belajar, jadwal, dan pengumuman sekolah secara *real-time*.
* **💳 Digital Cash & Finance Tracker:** Fitur transparan untuk pencatatan kas kelas dan keuangan siswa yang akuntabel serta mudah dipantau.
* **📚 Vocational Learning Portal:** Akses materi kejuruan interaktif berbasis web yang ringan, cepat, dan mudah dipahami.

---

## 💻 4. Technology Stack
Ditenagai oleh teknologi web standar industri yang ringan dan performa tinggi:
* **Frontend Core:** HTML5, CSS3, Modern JavaScript (ES6+)
* **Styling Engine:** Custom Modern CSS Framework & Glassmorphism Design UI
* **Deployment & Cloud Infrastructure:** Vercel Global Edge Network

## 🚀 7. Local Installation & Run Instructions
Ingin menjalankan proyek ini secara lokal di komputermu? Ikuti langkah berikut di terminal:

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/ketutdastrawiguna-max/smk-portfolio.git
   ```
2. **Masuk ke direktori proyek:**
   ```bash
   cd smk-portfolio
   ```
3. **Jalankan aplikasi:**
   Buka file `index.html` langsung di browser pilihanmu atau gunakan ekstensi *Live Server* di editor kode.

## 📊 8. System Architecture & Data Flow
```text
[ User Browser ] 
       │
       ▼ (HTTPS Request)
[ Vercel Cloud Hosting ] ──> [ Static Frontend Assets (HTML/CSS/JS) ]
```
Arsitektur berbasis *client-side rendering* murni yang terhubung langsung melalui infrastruktur *cloud* Vercel untuk menjamin kecepatan muat halaman yang instan di berbagai perangkat.
